# Changelog

All notable user-visible changes to the MicroBin TOS application package.

## 2.1.4-1 — 2026-11-14

### Added
- First release. MicroBin (`danielszabo99/microbin:2.1.4`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8129 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/microbindocker/`.
